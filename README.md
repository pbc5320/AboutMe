# Hi, I'm Pamela Carey 👋

PhD student in Political Science at **Penn State**, studying security, conflict, and the language that frames them. CyberCorps Scholarship for Service Scholar.

## What I work on

- **Nuclear negotiations and bargaining failure.** My master's thesis, *Dividing the Indivisible*, uses ordered logistic regression on 30 post-Cold War negotiations.
- **Semantic prosody in historical corpora.** Building a Python detection algorithm for 18th- and 19th-century Gothic fiction and British newspapers, with multilingual adaptation in mind (ARL Walker Graduate Assistantship).
- **Repression, political violence, and state failure.** Cross-national quantitative work on autocratic governance and terrorist lethality.
